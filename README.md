# Arabic AI Humanizer 🤖

تطبيق ويب ذكي مبني بـ **FastAPI** و **Python**، مخصص لتحويل النصوص المولدة بواسطة الذكاء الاصطناعي إلى صياغة بشرية طبيعية، سلسة، ودقيقة باللغة العربية.

## 🚀 المميزات الرئيسية
* **واجهة مستخدم تفاعلية:** تصميم عصري وسهل التعامل مع النصوص.
* **تحليل الذكاء الاصطناعي:** أدوات لقياس وتحليل نسبة النصوص البشرية مقابل نصوص الذكاء الاصطناعي.
* **دعم اللغة العربية:** معالجة متقدمة ومصممة خصيصاً لتناسب السياق اللغوي والبلاغي العربي.

## 🛠️ التقنيات المستخدمة
* **Backend:** Python, FastAPI, Uvicorn
* **AI Integration:** Groq API
* **Frontend:** HTML5, CSS3, JavaScript
